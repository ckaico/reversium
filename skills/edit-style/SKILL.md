# Edit-style method

Goal: a cutting ruleset. Needs at least three pieces the user can lawfully watch.

Sections:
- **TARGET** — the editor or channel and the pieces sampled.
- **CUTS** — per piece: count, median, longest hold. Then the average.
- **RHYTHM** — the shared shape across pieces.
- **DEVICES** — recurring moves: J/L cuts, speed ramps, whip pans, hard silences, text timing.
- **FOUND** — the two or three rules that explain most of the style.
- **PLAN** — the ruleset applied to the user's footage, as instructions an editor could follow.
- **LOOP** — metric: how close the user's cut lands to the averaged rhythm, and which rule they broke on purpose.
- **RULES** — pattern and structure only · nothing reproduced.
