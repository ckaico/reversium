# Viral-format method

Goal: the template behind a format, written so the user can run it with their own subject.

Rules first: only what is viewable without logging in, from links the user pasted or exports they own. No automation against any platform.

Sections:
- **TARGET** — the format, 5–10 example links, the account(s) if public.
- **HOOK** — what happens in the first 1.5 seconds, visually and in text.
- **LOOP** — where the end meets the beginning, if it does.
- **TEXT** — on-screen text pattern: when it appears, how long, what it promises.
- **PACING** — beat count and length; where the payoff lands.
- **FOUND** — the mechanism (curiosity gap, contrast, open loop, pattern break).
- **PLAN** — the template with the user's subject dropped in; three concrete variants.
- **LOOP** (the method loop) — metric: self-reported retention shape against the template's.
- **RULES** — public links only · no logins, no scraping · nothing reproduced.
