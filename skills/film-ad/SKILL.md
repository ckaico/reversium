# Film / ad method

Goal: how it was made, as a plan the user can shoot their own version from. Method, never footage.

Sections:
- **TARGET** — title, length, where it is viewable.
- **CUTS** — count, median shot length, longest hold and where it falls. Timecodes.
- **RHYTHM** — how shot length changes over time (accelerating, steady, breath-then-sprint). Describe the curve.
- **LENSES** — wide / normal / long / macro pattern; movement (locked, handheld, push-in).
- **SOUND** — when music enters and exits, when it goes silent, where the voice sits.
- **FOUND** — the one structural trick that makes it work (the hold before the reveal, the match cut, the silence).
- **PLAN** — a shot list for the user's own piece using the same structure with their subject.
- **LOOP** — the metric: the rhythm curve of their cut against the reference.
- **RULES** — method not footage · nothing from the original reused · stills only as reference, not in the output.

If the user wants the look of an editor across many pieces rather than one piece, switch to `edit-style`.
